What's inside

MetricGraph

Discover & govern metrics

"Glean for financial metrics." Parses Excel, SQL, DAX, and Python to find every formula, normalizes it, clusters look-alikes, and surfaces conflicts.

  • Multi-language formula parsing & normalization
  • LLM labeling + semantic clustering
  • Conflict / governance issue detection
  • Approved metric registry with audit trail
  • Apply metrics to raw data (DuckDB, XIRR, ...)
FastAPI · Postgres/pgvector · Redis/RQ · MinIO · Next.js
ingest_engine

Watch & sync sources

A polling file-ingestion engine that watches source folders, content-addresses and compresses files, detects changes, and feeds them into MetricGraph.

  • Recursive watch with include/exclude globs
  • SHA-256 content hashing + zlib store
  • SQLite change-state & event log
  • Pluggable sinks (log / MetricGraph / webhook)
  • Composite fan-out sink for notifications
Python · httpx · SQLite · CLI (run / scan-once / status)
integration_hub

Notify & answer in chat

A FastAPI bridge that turns platform events into Slack/Teams alerts, files deduped Linear issues for conflicts, and answers metric questions from chat.

  • Inbound event webhooks (shared-secret verified)
  • Slack / Teams / Linear connectors
  • Auto Linear issues for conflicts (deduped)
  • Ask in Linear → reply from the registry
  • Slack slash commands & approve buttons
FastAPI · httpx · SQLite dedupe · Adaptive Cards · GraphQL
